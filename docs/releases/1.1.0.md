# Gantry 1.1.0 — Find the conversation. Pick up the work.

Your agents keep working. Gantry helps you see where they left off.

**Gantry 1.1** brings searchable conversations, live agent states, and richer
session records to your Mac — alongside the quota, context, MCP diagnostics,
and previewable setup fixes you already know.

**macOS 13+ · Apple silicon & Intel · Completely free, including for commercial use**

## What's new

- **Find the conversation you need.** Filter Sessions by title or project, then
  press Return to search conversation contents. Read matching passages, browse
  a project's history, and copy a resume command where the agent provides one.
- **Catch the moment your agent needs you.** Claude Code and Codex show Working
  or Ready; Claude Code also shows recorded permission waits. Optional notices
  flag waits and the completion or interruption of longer turns, with a way
  back to the session's app. Claude Code's own recap appears where recorded.
- **Understand why work stopped.** Session details show recorded usage limits,
  overloads, connection failures, and interruptions. Review Claude Code's
  permission decisions, commands worth a look, retry time, and compactions.
  Jump from a finding to the conversation that supports it.
- **Bring Cursor history into view.** Discover desktop conversations and their
  projects, search readable messages, and reveal their local records in Finder.
  Cursor usage, cost, and quota are unavailable.
- **Meet Antigravity support.** Inspect local conversations, recorded usage,
  configuration, and readable transcripts across Antigravity's supported local
  stores. Antigravity replaces Gemini CLI support in this release.
- **Get a clearer context picture.** Claude Code's context stack distinguishes
  MCP tools sent in full from tools deferred for search. Codex usage includes
  separately recorded remote-compaction tokens when full records are read.

These features build on Gantry's local workspace for **Claude Code, Codex,
Cursor, Antigravity, OpenCode, and Copilot CLI**. Coverage varies by tool;
[see supported records and limits](https://github.com/devin-lai/Gantry/blob/main/docs/compatibility.md).

## Try it in a minute

1. Download `Gantry-1.1.0.dmg`, compare its SHA-256 with `SHA256SUMS.txt`, and
   drag Gantry into Applications.
2. Open Gantry, read the welcome screen, and choose your MCP benchmarking
   preference.
3. Open **Sessions**, pick a project, and search for something you remember
   asking your agent. Open a result to return to the passage.

## Local records, clear limits

No Gantry account. No analytics telemetry. Session history stays on your Mac.
MCP benchmarks can launch configured servers or contact chosen endpoints;
those services can use their own credentials and make network requests.
This release has no built-in update feed. Use **Watch → Custom → Releases**
to hear about new versions.

Quota readings can be stale; costs are API-rate estimates, not subscription
bills. Older or large Codex rollouts can leave details unread. Claude Code
permission counts require records from 2.1.294 or later. Command review shows
recorded inputs, not what those commands changed. Older encrypted Antigravity
conversations cannot be read. Automatic permission-rule suggestions remain
disabled by default.
