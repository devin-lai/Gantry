# Gantry 2.0.0

Gantry 2.0 helps you carry work between Claude Code and Codex. The opt-in **Project Memory** pilot gives connected agents access to the project decisions and lessons you choose to keep.

- **Save and review.** Save memories in a project or import selected Claude Code notes. Review the exact text that can appear at startup, keep other notes for recall, and disable outdated memories.
- **Trace the handoff.** Inspect recorded memory calls and startup delivery in Sessions where local records support it. Optional work notes let a connected agent request a short excerpt of the prior session ending.
- **Resume the work.** Find a conversation, inspect recorded changes and current Git state, and resume supported sessions in Terminal. Gantry also covers cached quota and MCP configuration across supported tools.

**macOS 14.5+ · Apple silicon and Intel · Free for personal and commercial use**
