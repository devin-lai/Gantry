# Gantry 1.2.0 — Know what changed. Keep work moving.

Your agent stopped. Your work doesn't have to.

**Gantry 1.2** connects the conversation to what comes next: review recorded
file changes, check what is still uncommitted, copy a handoff note, and inspect
the configuration your next session will use.

## What's new

### Know what your agents changed

Sessions now bring recorded file edits into view: created, edited, deleted,
and moved files, with links back to the conversation and Finder. Current,
read-only Git checks distinguish uncommitted work from clean or subsequently
committed files. A filter helps you find sessions with uncommitted edits.

These records come from supported edit tools in Claude Code, Codex, Cursor,
and Antigravity. Shell-command side effects are outside the list, and Git
status does not establish which person or agent owns a change.

### Take useful context into the next session

**Copy handoff note** assembles the session's own recorded words, changed
files, current Git observations, commands worth reviewing, and resume command
where available. Sources, times, and cuts are labelled. Review the copied note
before pasting it into another tool.

Recent conversations are easier to reach from **Overview**, with explicit
copy-resume actions. Where recorded, a session ending on a usage limit can
show the other supported agent's cached quota reading and its freshness.

### Recover more of an older Codex conversation

When a selected older or large session has details that have not been read,
choose **Load session details**. Progress, Cancel, and retry keep the read
under your control. Recovered endings, file edits, and commands update the
existing session and persist locally. Unsupported, malformed, changing, or
over-limit records remain explicitly incomplete.

### Inspect capabilities for the project you're working in

Choose a tool and working directory in **Agents** or **Inventory**. Follow
skills, plugin components, and MCP servers to their sources without losing
your search or selected context.

MCP diagnosis identifies the relevant stage: configuration or policy,
executable, working directory, environment, initialization, or tool listing.
Checks show their freshness and masked evidence. A successful Gantry check
does not claim the coding tool itself loaded or approved the server.

### Make supported configuration changes with clearer feedback

Supported Claude Code and Codex changes explain their destination and scope,
preview the edit, create a backup, and re-read the result. Conflicting
controls and intervening file changes receive explicit outcomes. Guarded
Undo preserves later edits instead of silently overwriting them.

### A calmer workspace, with reliability fixes throughout

Softer light and dark colors, clearer search guidance, **⌘F** discovery,
Escape to clear search, and expandable usage detail make everyday inspection
easier. This release also fixes session parsing and caching, Codex titles and
API-rate estimates, configuration previews and writes, scan recovery, filters,
command review, and credential masking in process and MCP diagnostics.

## Try the new workflow

1. Install Gantry, then open **Sessions** and select a recent conversation.
2. Review its changed files and current Git state. If an older Codex session
   offers **Load session details**, use it to recover more recorded evidence.
3. Use **Copy handoff note** or **Copy resume command** where available.
   For setup work, open **Agents**, choose the tool and working directory,
   and follow a capability into its details.

Gantry works alongside **Claude Code, Codex, Cursor, Antigravity, OpenCode,
and Copilot CLI**, with different coverage by tool.
[See supported records and limits](https://github.com/devin-lai/Gantry/blob/main/docs/compatibility.md).

## Local records, clear limits

No Gantry account. No analytics telemetry. Session history stays on your Mac.
MCP checks can launch configured servers or contact chosen endpoints; those
services can use their own credentials and make network requests. Copied
handoff notes may contain private session content, so review before sharing.

Quota is cached; cost is an API-rate estimate, not your subscription bill.
Tool coverage varies, and incomplete records remain labelled. This build has
no built-in update feed. Use **Watch → Custom → Releases** for new versions.
