# Gantry 1.3.0 — Less hunting. More building.

The conversation is in one tool. The quota is in another. The broken MCP
server is buried in a config file.

**Gantry brings your local AI coding work into one native Mac app.** Find a
conversation, see what changed, understand the setup, and pick up the work.
Version **1.3** makes that daily loop easier to navigate and more dependable.

## Your projects look like projects again

Independent Codex conversations no longer turn their generated output folders
into a wall of mysterious project names. **Projects** stays focused on
workspaces. **Sessions → No project** keeps independent conversations easy to
find, with a shortcut from Projects.

Every conversation stays in Sessions. Its recorded title comes first; its
working folder remains available in Details. Search, counts, and project
totals use the same association, while missing or ambiguous metadata stays
explicitly uncertain.

## Find the session. Keep it in view.

Sessions gets a more focused layout: search, a day picker, useful filters, and
a **Columns** menu that lets you choose the details you care about. Those
column choices are remembered. Open the inspector and your selected session
stays in view.

Type to filter titles and projects; press **Return** to search conversation
contents. Review recorded file changes and current Git state, then copy a
handoff note or resume command where supported. Your next step is close to
the evidence that explains it.

![Gantry 1.3 Sessions with filters, selectable columns, and synthetic conversations](https://raw.githubusercontent.com/devin-lai/Gantry/main/assets/sessions-1.3.0-light.png)

## A workspace that fits the window you're using

Inventory controls wrap, tables use their available space, and inspectors
open at the minimum window size. Rules & Commands gets configurable columns;
Hooks gets a resizable split with an accessible divider.

This release also fixes narrow-window inspector crashes and macOS 27 table
focus: after clicking a row, keyboard navigation goes to the table. Light and
dark appearances share clearer alignment and more consistent spacing.

## More reliable where it matters

- **Find the MCP server you can see.** Search HTTP servers by their displayed
  hostname or endpoint. Redacted credential values stay out of search.
- **Find every shared skill source.** Each displayed home-relative path is
  searchable, including additional locations for the same skill.
- **Trust the preview.** Cleanup refuses files that were edited or replaced
  after preview, before moving any item in the batch. Supported configuration
  edits retain backups and guarded Undo.
- **Get timely quota warnings.** A delayed notification-permission answer no
  longer sends a warning whose reading expired or whose quota already reset.
- **See an estimate only when the model matches.** Unrecognized model names
  no longer inherit the price of a similarly named model. Cached estimates
  are refreshed for the corrected matching rules.
- **Read a consistent date and time.** Relative-day labels and handoff clocks
  now use the same time zone.

Further fixes cover session recovery, newer Codex records, transcript search
buffering, MCP response handling and cancellation, process diagnostics,
configuration writes, and interrupted reads. Large-history checks exercised
search across 3,000 synthetic sessions and detail reads up to 500 MB; these
are test workloads, not speed guarantees for every Mac.

## Try the 1.3 workflow

1. Open **Sessions**. Choose a project, **No project**, or all conversations.
2. Pick a day or search for something you remember. Open a result and inspect
   the recorded changes, ending, and current Git state.
3. Copy a handoff note or resume command where available. For setup questions,
   choose the tool and working directory in **Inventory** and follow a skill
   or MCP server back to its source.

**⌘K** jumps · **⌘F** finds Sessions search · **⌘R** refreshes · **⌘Z** undoes a
supported file edit.

## Local records. Clear boundaries.

No Gantry account. No analytics telemetry. Session history stays on your Mac.
MCP checks can start configured servers or contact chosen endpoints; those
services can use their own credentials and make network requests. Review
copied handoff notes before sharing them.

Coverage varies by tool. Quota is cached, costs are API-rate estimates rather
than subscription bills, and file-change lists cover recorded edit tools.
This build has no built-in update feed. Use **Watch → Custom → Releases** for
future versions.
