## Validation

- **2,757 tests passed, 9 skipped, 0 failed** in the final fixture run (2,766 tests, 583 suites), using an asserted isolated test home.
- The unmodified suite twice reported **2,756 passed, 9 skipped, 1 failed**: a relative-executable MCP fixture exceeded its one-second initialization budget. Focused runs reproduced the timeout. For diagnosis, only this fixture's budget was raised to five seconds in the disposable test copy; its five cases initialized in **0.9–2.7 seconds**, and the full fixture run then passed.
