## A short description

> Gantry is a native macOS dashboard for AI coding tools: inspect cached quota,
> startup context, MCP diagnostics, and setup findings with previewed file edits
> and Undo. Free for personal, non-commercial use; the app source is private.

## A little more context

> If your coding setup is spread across logs, instruction files, skills, hooks,
> and MCP servers, Gantry brings that local evidence into one workspace. It works
> alongside Claude Code, Codex, Cursor, Gemini CLI, OpenCode, and Copilot CLI,
> with different coverage by tool. The macOS 13+ public preview supports Apple
> silicon and Intel. It is ad-hoc signed and not notarized by Apple; read the
> official installation guide before the first launch.

## What to keep clear

- Gantry is an independent companion app; tool coverage varies. Quota coverage is for Claude Code and Codex, and Cursor coverage in this build does not include chat usage or quota.
- Costs are estimates at API rates, and quotas are locally cached readings. Avoid presenting them as billing data or promising savings.
- The public preview is free for personal, non-commercial use. Commercial, employer, and client use requires separate permission.
- Link to the official download rather than rehosting the DMG. The [license](../LICENSE) does not grant a general reuse license for branding, artwork, or documentation.
- Use synthetic examples when discussing a workflow. Never share private session content, credentials, account identifiers, or unredacted diagnostics.
