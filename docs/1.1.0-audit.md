## Distribution checks

The application was built in Release from a clean export of the private
`release/1.1` branch, with version 1.1.0 explicitly set for the build. Local
developer-signing configuration was excluded. A separate distribution copy
had debug symbols and local symbol-table entries stripped, then was re-signed
with distribution entitlements. All **74 file-backed Mach-O sections** across
both architectures match the original executable's section bytes.

The mounted app, property lists, signature, entitlements, resources, extended
attributes, disk-image filesystem, and uncompressed disk-image bytes were
inspected. Gitleaks scanned extracted bundle and disk-image strings, and the
public documentation and artwork. No credential matches, personal home paths,
or checked private identity markers were found. Bundle files have no extended
attributes. The disk image verifies and the mounted app's signature verifies.

The image contains only **Gantry.app**, an **Applications** shortcut,
**READ ME FIRST.txt**, **LICENSE.txt**, and **PRIVACY.txt**. It includes no
application source, debug-symbol archive, test bundle, provisioning profile,
private key, developer configuration, account database, or personal transcript.
Only the DMG and `SHA256SUMS.txt` are release assets; debug symbols stay private.
The public release commit and tag use a neutral automation identity.

## Validation and limits

The regression run reported **2,265 tests passed, four skipped, and zero
failures**. The separate SmokeTests and BenchTests suites were excluded because
they read the real home folder or start configured MCP servers. The release
passes the repository's universal-binary and macOS 13 dependency checks.

The stripped app reached its ready state in an isolated empty-home launch,
with personal-home reads and writes and network access denied. This verifies
launching on the test Mac, not every feature, Intel runtime behavior, or actual
runtime compatibility on macOS 13. Future agent formats can change.

Automated scans cannot prove the absence of every possible secret. The checksum
identifies these audited bytes; it does not authenticate a publisher or
represent Apple notarization. Follow the [installation guide](getting-started.md).
