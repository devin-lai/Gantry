## Package and privacy checks

The universal Release build came from an isolated, clean checkout of the
1.3 release branch. Untracked local configuration was excluded. A separate
distribution copy was stripped and ad-hoc signed; all 74 file-backed Mach-O
sections across the two architectures match the original build. The mounted
image passed disk-image verification and strict app-signature verification.

The image contains only **Gantry.app**, an **Applications** shortcut, and
**READ ME FIRST.txt**. The application contains its executable, property list,
package marker, signature resource seal, icon, and compiled asset catalog. It
does not bundle project skills, source files, test bundles, developer
configuration, signing certificates, provisioning profiles, or private keys.
The mounted files and directories have no extended attributes.

The compressed image and entire decompressed filesystem, including unallocated
space, were checked for local home paths, machine and signing identifiers,
private source revisions, and local Git identity markers in UTF-8 and UTF-16.
No checked markers were found. Gitleaks 8.30.1 found no secret patterns in
strings extracted from the decompressed filesystem. The promotional screenshot
uses synthetic data; its nonessential metadata was removed.

These checks apply to this artifact and the patterns and encodings inspected;
they cannot prove that every possible secret encoding is absent or describe
data a user later creates.

## Validation and limits

- A prior full fixture run passed **3,004 tests**, with 16 skipped. All 354
  tracked app, test, project, and configuration files match this release checkout byte for byte. The earlier test checkout also had a local signing configuration; the release checkout excluded it.
- The release rerun reported **3,003 passed, 16 skipped, and one failed**.
  The failed window-inspection test could not inspect its view while macOS
  reported that a lock-screen accessibility shield blocked the test window.
  That test passed in the prior run against those matching files.
- **22 distribution-harness checks passed.** The universal Release build and
  the image integrity, mounted signature, architecture, deployment-target,
  executable-section, and content checks passed.
- These checks ran on Apple silicon with macOS 27.0.1 and Xcode 27.1.
  Intel and macOS 14.5 runtime testing, clean-device installation, real-home
  scans, live MCP execution, and a full keyboard/VoiceOver review were not
  performed as part of this release verification.
