## Build and package

The universal Release archive was built with **Xcode 26.5** on a clean,
temporary macOS runner from the pinned release revision. Version, build,
architectures, and neutral build-path mappings were set explicitly. Local
developer signing configuration and untracked files were excluded.
The application source and private CI artifacts remain private.

A separate distribution copy had debug symbols and local symbol-table entries
stripped, build-machine metadata removed, and distribution entitlements applied
with an ad-hoc signature. All **72 file-backed Mach-O sections**
across both architectures match the original archived executable. No production
code was changed after the archive.

The image contains only **Gantry.app**, an **Applications** shortcut,
**READ ME FIRST.txt**, **LICENSE.txt**, and **PRIVACY.txt**. The app has six
files: its executable, property list, package marker, signature resource seal,
icon, and compiled asset catalog. It includes no application source, test
bundle, developer configuration, signing certificate, provisioning profile,
private key, account database, or personal transcript.

The public release assets are the DMG and SHA256SUMS.txt. GitHub's generated
repository archives contain the public documentation and artwork.

## Sensitive-data inspection

The mounted bundle, property lists, entitlements, signature, resources,
symlinks, filesystem contents, and extended attributes were checked.
The compressed image and the entire decompressed filesystem, including
metadata and unallocated bytes, were scanned for private home paths and known
private identity and signing markers in UTF-8 and UTF-16 encodings.

**No checked private identity markers, personal home paths, or credential
matches were found.** The mounted image's files and directories have no
extended attributes. The image's filesystem contains no quarantine,
provenance, or download-origin metadata. Gitleaks 8.30.1 reported no leaks
in extracted bundle/image strings or the public documentation and artwork.

Screenshots use synthetic demonstration data and contain no personal session
history. Their embedded text and camera metadata were removed.

These results describe the inspected artifact and the checks performed.
They do not establish the absence of every possible secret encoding or
describe data a user later creates while using the app.

## Validation

- **2,915 tests passed, 12 opt-in tests skipped, 0 failed** in the final Xcode fixture run on Apple silicon/macOS 26.6.2. Parameterized tests produced **3,239 passing executions**. Real-home SmokeTests and configured-service BenchTests were excluded.
- Universal Release archive, both architecture/dependency checks, strict
  mounted-app signature verification, disk-image verification, and all
  executable-section comparisons passed.
- The feature audit covered launch, Overview, Doctor, Projects, Sessions,
  Live Runtime, all six inventory categories, agent settings, navigation,
  Settings, help, diagnostics, cleanup, recovery, and distribution.
- The audit generated **300 UI fixtures** and **26 complete application
  captures** across 13 destinations in light and dark appearance, including
  the minimum content size. Interactive checks covered search, inspectors,
  Settings, shortcuts, and a synthetic configuration Apply → Undo round trip.
- **20 distribution-harness checks** and syntax checks for **15 shell tools**
  passed. **11 synthetic resource probes** exercised large histories,
  cancellation, bounded search results, cache rejection, and repeated
  timeline reads. These measurements are workload-specific.

The release qualification also corrected inconsistent time-zone formatting
and made native table tests yield for the app's queued layout measurement.
The visibility assertions were retained. The Xcode test home was explicitly
isolated; no local-account or configured-service integration tests were used.

The mounted, packaged app reached first paint, completed its empty-home scan,
and generated its ready receipt and screenshot on Apple silicon/macOS 27.0.1.
Personal-home access and network access were denied by a verified sandbox
profile. Automatic MCP checks and notifications were disabled. The installed
Gantry copy was not replaced.

## Remaining limits

Actual Intel and minimum-version macOS 14.5 runtime qualification were not
performed. Universal slices and deployment targets were checked statically.
Real-account vendor integrations, OS login-item registration, and the live
notification-permission flow remain separate integration checks.

The macOS 27 menu-bar popover has a known VoiceOver navigation limitation;
the main window provides the corresponding quota and runtime views.
See [compatibility](compatibility.md). The app remains ad-hoc signed and
unnotarized.
