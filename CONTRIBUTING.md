# Help improve Gantry

Bug reports, workflow suggestions, and documentation improvements are welcome.
The application source is private, so this repository does not accept changes
to the application's implementation.

Before opening an issue, search existing reports and include the Gantry build,
macOS version, relevant agent version, and a minimal description of the problem.
You do not need to attach your session history. For documentation, open a small
pull request explaining the correction; do not include proprietary source or
internal development files.

Review every report or screenshot before sharing. Remove API keys, tokens,
account identifiers, private project paths, and confidential prompts. A local
diagnostic report is a starting point, not a guarantee of complete redaction.

Use the [issue forms](https://github.com/devin-lai/Gantry/issues/new/choose) for
bugs and feature requests. See [SECURITY.md](SECURITY.md) for sensitive reports.
Be constructive, describe the evidence, and respect other users' privacy.
