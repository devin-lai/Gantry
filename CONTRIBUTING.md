# Help improve Gantry

Bug reports, workflow suggestions, and documentation improvements are welcome.

For help using Gantry, [ask in Q&A](https://github.com/devin-lai/Gantry/discussions/categories/q-a).
For an early workflow suggestion, [start in Ideas](https://github.com/devin-lai/Gantry/discussions/categories/ideas).
The maintainer aims to answer questions and review ideas weekly, on a best-effort
basis; there is no guaranteed response time. Useful answered questions are added
to the [FAQ](docs/faq.md), with a link to the discussion.

Before opening an issue, search existing reports and include the Gantry build,
macOS version, relevant agent version, and a minimal description of the problem.
You do not need to attach your session history. For documentation, open a small
pull request explaining the correction; do not include confidential code or
internal development files.

Review every report or screenshot before sharing. Remove API keys, tokens,
account identifiers, private project paths, and confidential prompts. A local
diagnostic report is a starting point, not a guarantee of complete redaction.

Use the [issue forms](https://github.com/devin-lai/Gantry/issues/new/choose) for
bugs and feature requests. See [SECURITY.md](SECURITY.md) for sensitive reports.
Be constructive, describe the evidence, and respect other users' privacy.

For documentation or translation corrections, use the
[documentation form](https://github.com/devin-lai/Gantry/issues/new?template=documentation.yml)
or open a small pull request. Keep the English and Chinese introductions aligned
on tool coverage, privacy, release signing, and free commercial use.
