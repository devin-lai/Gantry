# Security reports

Do not publish credentials, private transcripts, exploit details, or personal
information in public issues or pull requests.

For a confidential report, use GitHub's **Report a vulnerability** option on
this repository's Security page when it is available. If private reporting is
unavailable, open an issue asking for a private contact method, without including
the vulnerability details or sensitive data.

A useful report identifies the Gantry version and build, the affected behavior,
a minimal reproduction using synthetic data, and the potential impact. Do not
attach real agent credentials, unredacted diagnostics, or crash dumps containing
private paths.

Releases are distributed through this repository's Releases page. Check the
published SHA-256 before opening a download. A checksum verifies bytes, not
notarization or publisher identity. Build 79's prepared public preview is ad-hoc
signed and not notarized by Apple.
